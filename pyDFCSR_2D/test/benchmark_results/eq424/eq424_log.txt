--- CHECK 1: symbolic (no numbers, no lattice) ---

  quadratic coefficients from the derivation:
    A = 1 - 1/tau**2
    B = -2*T/tau - 2*n_dot_q
    C = -T**2 + q2

  substituting each candidate back into the quadratic (0 => it is a root):
    Eq 4.24 as printed  -> T**2*tau**2 + 2*T*n_dot_q*tau + n_dot_q**2*tau**2 - q2*tau**2 + q2
    single power of tau -> 0

  sympy's own solve(), for a third independent confirmation:
    tau*(T + n_dot_q*tau - sqrt(T**2*tau**2 + 2*T*n_dot_q*tau + n_dot_q**2*tau**2 - q2*tau**2 + q2))/(tau**2 - 1)
    tau*(T + n_dot_q*tau + sqrt(T**2*tau**2 + 2*T*n_dot_q*tau + n_dot_q**2*tau**2 - q2*tau**2 + q2))/(tau**2 - 1)

  with an axis intercept b, rewritten in Tb = T - b/tau:
    tau*(Tb + n_dot_q*tau - sqrt(Tb**2*tau**2 + 2*Tb*n_dot_q*tau + n_dot_q**2*tau**2 - q2*tau**2 + q2))/(tau**2 - 1)
