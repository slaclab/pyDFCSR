PART 1: what is the controlling scale?
======================================================================================
Interpolate the near-region cell at which each shear reaches 1% accuracy.

   shear     amp  zbins@1%    cell@1%   /sigma_z  /sigma_xi
       2     1.3       200     4.17um     0.1427      0.058
      20    65.9       400    13.95um     0.0271      1.112
      50   166.8       800    16.08um     0.0118      1.299

If the /sigma_xi column is roughly constant while /sigma_z is not, the
requirement is set by the transverse support width, and the node count must
scale as (near length)/sigma_xi ~ tilt amplification.

======================================================================================
PART 2: per-region allocation vs a flat zbins
======================================================================================
Near region gets cell = c * sigma_xi; far regions get 200 nodes each
(section 6j: the far edge is exactly invariant, so equal nodes there is waste).
Accuracy is measured against the SAME shear's zbins=3200 reference, and
cost as the mean total column count per wake point -- flat zbins=3200 is 9600.
